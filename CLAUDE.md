# Project notes

## Content deliverables
Any memo, brief, recap, or summary produced for this project (project briefs,
day scripts, strategy docs, etc.) must be delivered as a styled HTML page
(published as an Artifact), not as a plain `.md` file. This is a standing
preference from the user — apply it by default going forward without being
asked again.

Match the existing visual system used in `src/App.css`: dark terminal
aesthetic, Space Mono for labels/data, Inter for body text, mint (`#00E5A0`)
accent, coral (`#FF6B35`) secondary.

## Character / positioning (source of truth)
- **Builder:** The user built the quant trading system themselves, solo, using
  Claude Code. Do NOT credit "me and my dad" or any co-builder — that framing
  was tried and explicitly corrected. Use first-person singular ("I built
  this") in all scripts, captions, and docs.
- **The game:** Never name or describe "the game" the system runs inside, and
  don't use a "[the game]" placeholder. The audience already knows the
  context — drop game references entirely rather than gesturing at them.
- **Positioning:** The system is already built and proven (months of runtime),
  not something being built live on camera. Daily posts are insights from a
  system that's already working. Payoff: at 100K followers, release a paid
  course teaching people how to build the same system themselves.
