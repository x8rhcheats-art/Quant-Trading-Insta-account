# Project notes

## Content deliverables
Any memo, brief, recap, or summary produced for this project (project briefs,
day scripts, strategy docs, etc.) must be delivered as a styled HTML page
(published as an Artifact), not as a plain `.md` file. This is a standing
preference from the user — apply it by default going forward without being
asked again.

Match the existing visual system used in `src/App.css`: dark terminal
aesthetic, Space Mono for labels/data, Inter for body text, mint (`#00E5A0`)
accent, coral (`#FF6B35`) secondary.
